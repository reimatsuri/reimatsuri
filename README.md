### 1. HR Record Solutions
**Multi-Company Employee Records Management Platform**

A web-based employee records management system designed for small and medium-sized businesses. It provides a centralized platform where companies can manage employee information and organize their digital documents.

**Key Features**
- Employee information management and records
- Digital document upload and storage
- Folder creation and document organization
- Document search and filtering
- Multi-company accounts and data isolation
- User and role management
- Company storage quota monitoring
- Customer support and administrator communication
- Super Admin company management

**Technology Stack**

Next.js · TypeScript · Tailwind CSS · Django REST Framework · MongoDB Atlas

### 2. MediSure
**Medication Management and Reminder Application**

A mobile application designed to help elderly individuals manage their medications while allowing caregivers to monitor medication schedules and adherence.

**Key Features**
- Medication information and schedule management
- Medication reminders and alarm notifications
- Caregiver and elderly account linking
- Medication history and adherence reports
- Prescription scanning and information extraction
- Camera-based medication identification using a trained machine learning model
- Push notifications for medication reminders
- Caregiver notifications for missed medications
- Voice assistance and elderly-friendly interface

**Technology Stack**

React Native · TypeScript · Django REST Framework · Python · MongoDB Atlas · Firebase Cloud Messaging · Gemini AI · ONNX Runtime
